# 墨灵小课堂 · 制作模板

小课堂全部用 ChatCut 动态图形（MG）+ 蕾姐数字人声音制作，不生成视频。每课只换文字数据和时间点。

样片：ChatCut 项目「墨灵记 第3集 墨灵小课堂 样片（睛）」，时长约 3 分 13 秒。

## 流程

1. 按本课脚本写讲稿，分 7 段（见下方第 1 课讲稿）。
2. 用「蕾姐新数字人声音」逐段生成配音，每段一次，不出多版本（只花配音积分）。
3. 拿配音的逐字时间（语音识别出时间戳），算出每张卡的出现时间。
4. 把 7 个模板放到时间线上，每个实例填本课数据（propertyOverrides）。
5. 生词段：同一条配音按词切开，每个词后留 2 秒给学生跟读；小测段：答案前留 3 秒思考。
6. 本地导出（不走云端渲染）。

## 七个模板

| 模板 | 用途 | 主要属性 |
|---|---|---|
| 片头 | 课次、课文标题、本集的字（墨晕显现） | lesson, title, episode, hanzi, pinyin, revealAt |
| 生词总览 | 本课生词一览 | words（`词\|拼音;词\|拼音`）, lesson |
| 生词卡 | 单个生词 + 「跟我读」提示 | zh, py, en, idx, total, echoAt |
| 汉字精讲 | 古文字描红 → 旋转/变成今字 → 部件合成 → 公式；右侧要点、同部首字、拓展词 | hanzi, pinyin, ancient（none/eye/snake/foot）, tAncient, tRotate, tModern, partA, partB, layout（lr/tb）, tCompose, notes（`秒\|文字;;秒\|文字`）, related, relatedLabel, tRelated, extra, extraPy, tExtra |
| 句型 | 两个句型（关键词高亮）+「你来说」 | p1, p1ex, hl1, p2, p2ex, hl2（多个用 `\|`）, prompt, t1, t2, tPrompt |
| 小测 | 选择题 + 思考倒计时 + 揭晓 | num, q, a, b, c, answer, tThink, tReveal |
| 结尾 | AI 陪练问题 + 入口 + 下一课预告 | q, cta, next |

时间属性都是该卡片内的秒数，`-1` 表示不用。新字需要新的古文字图形时，在「汉字精讲」模板的 `glyphPaths` 里加一组 SVG 路径即可。

## 第 1 课讲稿（蕾姐）

| 段 | 讲稿 | 配音时长 |
|---|---|---|
| 开场 | 大家好，我是蕾姐。欢迎来到墨灵小课堂！今天我们学HSK二级第一课，《九月去北京旅游最好》。这一集，小砚找回的字是：眼睛的睛。 | 12.2 秒 |
| 生词 | 先来读生词。我读一遍，你跟我读一遍。旅游。觉得。最。为什么。也。运动。踢足球。一起。要。新。它。眼睛。 | 16.9 秒 |
| 睛 | 今天最重要的字，是眼睛的睛。左边是目。很久很久以前，人们画眼睛，是横着画的。后来，眼睛竖起来了，就变成了今天的目。右边是青，青墨镇的青。青告诉我们怎么读：青，睛，是不是很像？带目字旁的字，都和眼睛有关系：眼、睛、看。所以，画龙点睛，就是给龙画上眼睛。 | 29.2 秒 |
| 它 足 最 | 再看三个字。第一个，它。它最早画的是一条蛇。古时候，人们最怕蛇，见面就问：今天没有碰到蛇吧？后来，它用来说动物和东西，比如：它叫花花。第二个，足。足的上面是膝盖，下面是脚。有足字旁的字，都要用脚：踢、跑、跳。踢足球！第三个，最。最的下面是取，一只手抓住一只耳朵。抢在最前面，拿到最多，就是最。 | 34.3 秒 |
| 句型 | 再学两个句型。第一个：什么时候去最好？九月去北京旅游最好。第二个：不A也不B。九月的北京，不冷也不热。现在你来说一说：几月去你的国家旅游最好？为什么？ | 17.8 秒 |
| 小测 | 小测试，准备好了吗？第一题：哪个字是目字旁？A，踢。B，睛。C，新。答案是B，睛。第二题：它，最早画的是什么动物？A，猫。B，鱼。C，蛇。答案是C，蛇。第三题：我什么喜欢踢足球？A，最。B，为什么。答案是A：我最喜欢踢足球。 | 27.6 秒 |
| 结尾 | 你最喜欢什么运动？为什么？去和小砚说一说吧！我们下一课见，拜拜！ | 7.2 秒 |

配音合计约 2 分 25 秒，加上跟读和思考留白，成片约 3 分 13 秒。

以上是 v1（全中文）。ChatCut 项目里的原时间线保留不动，可直接当「全中文版」用。

## v2 双语版（HSK 2–3 默认）

时间线：「HSK2-1 双语版 v2（拼音+中英字幕）」，时长约 4 分 10 秒。

### 语言策略

| 级别 | 旁白 | 屏幕 | 字幕 |
|---|---|---|---|
| HSK 1–3 | 英文讲解；汉字、生词、例句用中文读 | 所有中文大字上方带拼音，每张卡片附英文 | 中英双行，烧录在画面里 |
| HSK 4+ | 全中文 | 拼音只留生词 | 中文；英文改成可选软字幕 |

「语言切换」用软字幕实现：`subtitles/` 里有 `zh`、`en`、`zh-en` 三套 SRT/VTT，上传 YouTube / B 站 / 自有播放器时作为字幕轨道，观众可自己切换。模板全部数据驱动，换一份讲稿重新配音即可出全中文版或其它语言版。

### 讲稿写法（给数字人配音）

- 中文部分单独成句，用「。」隔开：`In this episode, 小燕 found a character. 睛。眼睛的睛。 Eye.`。中文夹在英文句子中间时容易读错。
- 「小砚」配音稿写「小燕」（同音，读得准）；字幕和画面仍写「小砚」。
- 数据在 `tools/l01/script.py`（讲稿 + 中英字幕）和 `tools/l01/content.py`（卡片文字）；拼音用 `tools/l01/py.py` 生成，内含多音字/轻声/变调的校正词表（觉得、眼睛、什么、一只、不热……）。
