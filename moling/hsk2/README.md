# 《墨灵记》第一季 · HSK2 故事课

故事集从第 3 集起，按《HSK标准教程 2》的课序一课一集，共 15 课。第 1、2 集是序章（世界观和角色介绍）。

每集由两部分组成：

| 部分 | 时长 | 内容 |
|---|---|---|
| 故事 | 约 2 分钟 | 一条故事线把本课生词全部用上；角色台词复现课文原句的句型；结尾找回一个「失落的字」 |
| 墨灵小课堂 | 约 3 分钟 | 小砚主讲、团团带读：汉字精讲（重点）→ 句型 → 课文对照 → 小测 → AI 陪练衔接 |

成片出两个版本：**完整教学版**（约 5–6 分钟）和**纯故事版**（只剪故事部分，约 2 分钟）。

## 每集「本集的字」的选法

- 必须是本课生词里的字（或本课生词的组成字）。
- 字源要好讲、能画成动画（象形、会意，或部件有故事）。
- 这个字在故事里「失落」，找回它就是本集的高潮。

伏笔安排：
- **无名**：每集结尾都有一个远景镜头。
- **呱掌柜的秘密**：第 3 集结尾开头，第 17 集回收。
- **团团和无名出自同一方砚台**：第 13 集暗示，第 15 集揭开。
- **「睛」和「晴」**：第 3 集和第 16 集首尾呼应，两个字都以「青」表音。
