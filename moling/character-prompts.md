# 《墨灵记》九位角色形象设定提示词

依据 `assets/characters/` 中的设定图和 `data.js` 里的外观设定整理。

## 用法

1. 拼接顺序：**统一画风** + **角色描述** + **排版**。
2. 生成时一定要把对应的设定图（`assets/characters/0X-*.jpg`）作为参考图一起传入，保持长相一致。
3. 英文提示词在 Midjourney、即梦、可灵、Seedance 等工具里都比较稳定。

## 统一画风（放在最前面）

```text
New Chinese style stylized 3D animation character design sheet, soft Song-dynasty muted palette (grey-blue, celadon green, ivory, ink black, persimmon orange accents), soft diffuse studio light, gentle subsurface skin, fine fabric and fur detail, ink-wash texture on clothing edges, elegant and warm, Pixar-quality rendering with traditional Chinese painting aesthetics. Plain pale grey-blue seamless background, soft floor shadow. No text, no watermark.
```

## 排版（放在最后）

```text
Full body, shown 2–3 times side by side on the same sheet: front view, three-quarter view, and one expressive pose, consistent design across all views.
```

### 三视图排版（固定形象用）

```text
Full body, the same character shown three times side by side evenly spaced on one sheet: front view, exact side profile view facing right, back view; consistent design, proportions and colors across all three views, neutral standing pose, feet on the same ground line. No text, no labels.
```

## 延伸用法

- **场景图**：去掉「排版」，把画风里的背景换成场景描述，例如 `standing on a stone bridge in a Huizhou water town`。
- **九人合照**：传入全部九张参考图，加上 `the nine characters standing in a row, lineup`（参考 `assets/10-lineup.jpg`）。
- **视频首帧转动画**：参考 `data.js` 里各集分镜 `shots[].prompt`，开头加 `New Chinese style stylized 3D animation, muted soft palette, soft light.`，结尾加 `Keep character designs exactly as in the first frame. No text.`
